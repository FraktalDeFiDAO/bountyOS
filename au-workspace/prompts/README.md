# Prompt Pack

This folder contains reusable prompts for setting up bounty projects in the AU workspace.

## Files

- `orchestration_prompt.md`: coordinates setup across multiple bounties/projects.
- `new_bounty_project_setup_prompt.md`: reusable prompt for setting up one bounty project.
- `projects/*.setup.prompt.md`: concrete prompt per tracked bounty.

## Usage

1. Start with `orchestration_prompt.md` when batch-creating/updating projects.
2. Use `new_bounty_project_setup_prompt.md` for one-off bounty setup.
3. Use project-specific prompt files for fast, pre-filled setup tasks.
