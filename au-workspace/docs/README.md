# Documentation Index

This folder contains the complete operational documentation for the AU multi-project bounty workspace.

## Start here

1. `complete-reference.md`: full command reference, data model, workflows, and runbooks.
2. `current-state.md`: current registered projects and tracked bounties snapshot.
3. `layout.md`: why files/folders are organized this way.
4. `progress.md`: quick reference for bounty progress tracking commands.
5. `../scripts/generate_current_state.sh`: regenerates `current-state.md`.
6. `../prompts/orchestration_prompt.md`: orchestrates multi-bounty setup.
7. `../prompts/new_bounty_project_setup_prompt.md`: reusable setup prompt template.
8. `../prompts/projects/*.setup.prompt.md`: pre-filled setup prompts per tracked bounty.

## Scope

These docs cover:
- Workspace architecture and naming conventions
- `au` CLI command behavior
- Project and bounty tracker file formats
- Multi-bounty parallel execution workflow
- Existing project inventory and tracked bounty registry
